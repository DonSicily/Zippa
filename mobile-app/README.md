# 📱 Bestiez Mobile App (React Native / Expo)

The student-facing Gen-Z marketplace app. Designed with a playful, relaxed UI using heavy rounded corners, soft shadows, and a vibrant color palette.

## 🎨 Design System
- **Primary:** Playful Purple (`#6C63FF`)
- **Accent:** Vibrant Mint (`#00F5D4`)
- **Highlight:** Sunshine Yellow (`#FFE66D`)
- **Typography:** System fonts with heavy font weights (800/900) for headings.
