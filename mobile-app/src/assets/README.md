#  Bestiez Mobile App Assets

To complete the build, please add the following image files to this directory:

1. `icon.png` (1024x1024) - The main app icon. Use a playful purple background with a white 'B'.
2. `splash.png` (1284x2778) - The splash screen image. 
3. `adaptive-icon.png` (1024x1024) - For Android adaptive icons.
4. `favicon.png` (48x48) - For the web version of the Expo app.

*Tip: You can use Canva or Figma to quickly generate these using our brand colors (Purple: #6C63FF, Mint: #00F5D4).*
