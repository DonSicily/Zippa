# 🔤 Bestiez Custom Fonts

To get the exact relaxed, youthful typography, download and place these free Google Fonts in this folder:

1. `Poppins-Bold.ttf`
2. `Poppins-Black.ttf` (For the heavy 900 weight headings)
3. `Montserrat-Regular.ttf` (For body text)
